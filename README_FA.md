# کهکشان یادداشت‌ها

این بسته یک نمونهٔ آماده از نمایش یادداشت‌های فارسی به شکل کهکشان سه‌بعدی است.

## فایل‌ها
- `index_notes.py`: همهٔ فایل‌های `.md` داخل پوشهٔ `notes/` را می‌خواند و `web/data.js` می‌سازد.
- `web/index.html`: رابط سه‌بعدی و پنل یادداشت‌ها.
- `web/data.js`: دادهٔ ساخته‌شده برای ۳۰ یادداشت نمونه.
- `server.py`: سرور سادهٔ پایتون روی پورت ۸۸۰۰ که فقط پوشهٔ `web/` را ارائه می‌کند.

## اجرا روی کامپیوتر
۱. ZIP را از حالت فشرده خارج کنید.
۲. Python 3 را نصب داشته باشید.
۳. در پوشهٔ `galaxy_notes` اجرا کنید:
   `python index_notes.py`
۴. سپس اجرا کنید:
   `python server.py`
۵. در همان دستگاه مرورگر را باز کنید و به `http://localhost:8800` بروید.

برای مشاهده روی گوشی، `localhost` گوشی به کامپیوتر اشاره می‌کند، نه کامپیوتر دیگر. گوشی و کامپیوتر باید روی یک Wi-Fi باشند و به‌جای `localhost` از IP محلی کامپیوتر استفاده کنید. این بسته از اینجا نمی‌تواند روی دستگاه شخصی شما سرور را اجرا کند؛ سرور باید روی دستگاهی که فایل‌ها روی آن هستند اجرا شود.

## یادداشت‌های خودتان
فایل‌های Markdown را در `notes/` قرار دهید. هر فایل بهتر است با عنوانی مانند `# عنوان یادداشت` شروع شود. زیرپوشه‌ها به‌عنوان دسته‌بندی استفاده می‌شوند. بعد از اضافه/ویرایش یادداشت‌ها، `python index_notes.py` را دوباره اجرا کنید.


## پرسش‌وپاسخ از روی یادداشت‌ها
- تنظیمات خصوصی در `config.json` در ریشهٔ پروژه است، نه در `web/`.
- مقدار پیش‌فرض `provider` برابر `claude-cli` است. سرور برای این گزینه دستور `claude -p` را اجرا می‌کند. گزینهٔ `codex-cli` از `codex exec` استفاده می‌کند.
- برای API می‌توانید `provider` را `anthropic-api` یا `openai-api` بگذارید و کلید را خودتان در `config.json` وارد کنید. کلید هرگز در مرورگر قرار نمی‌گیرد.
- سرور امتیاز هم‌پوشانی واژه‌ها را محاسبه می‌کند، تطبیق عنوان را وزن بیشتری می‌دهد و شش یادداشت برتر را به مدل می‌فرستد.
- تاریخچهٔ کوتاه پرسش و پاسخ در حافظهٔ همان فرایند سرور نگهداری می‌شود و با راه‌اندازی مجدد پاک می‌شود.
- پس از تغییر یادداشت‌ها، ابتدا `python index_notes.py` را اجرا کنید.
- برای استفاده از CLI، دستور مربوطه باید روی همان دستگاه نصب و احراز هویت شده باشد. سرور به‌تنهایی CLI یا اشتراک را نصب نمی‌کند.
- `config.json` توسط سرور ارائه نمی‌شود؛ سرور فقط `web/` را برای فایل‌های استاتیک ارائه می‌کند و مسیر `/ask` را جداگانه مدیریت می‌کند.


## ورودی و خروجی صوتی
- دکمهٔ 🎙 با `webkitSpeechRecognition` و زبان `fa-IR` گفتار را به متن تبدیل می‌کند و همان مسیر `/ask` را صدا می‌زند. این قابلیت به پشتیبانی مرورگر و معمولاً اتصال شبکه نیاز دارد؛ در Chrome/Edge بهتر کار می‌کند.
- پاسخ‌ها با `speechSynthesis` خوانده می‌شوند. اگر صدای فارسی موجود باشد، ابتدا صدای فارسی و در اولویت نام Farid انتخاب می‌شود.
- اگر صدای فارسی موجود نباشد، رابط از مسیر `POST /speak` فایل MP3 می‌گیرد. برای این حالت فقط یک بستهٔ اضافه لازم است:
  `python -m pip install edge-tts`
- `/speak` از صدای `fa-IR-FaridNeural` استفاده می‌کند. اتصال اینترنت برای این سرویس لازم است.
- اولین لمس روی میکروفون یا دکمهٔ پرسیدن، اجازهٔ پخش صدا را در مرورگر فعال می‌کند. در صورت بی‌صدا بودن، یک بار دیگر روی صفحه لمس کنید.
